Politique de confidentialité

1. Données traitées

Mail Workflow est un outil d’analyse locale de boîtes mail. Les emails sont téléchargés depuis votre compte Gmail ou Outlook vers votre navigateur, puis écrits dans des fichiers JSONL sur le dossier que vous avez choisi sur votre ordinateur.

  • Aucun contenu d’email n’est stocké en base de données distante.
  • Les fichiers d’emails et de métadonnées sont créés uniquement dans le dossier local que vous sélectionnez via l’API File System Access.

2. Données qui transitent par le serveur

Le serveur Node.js/Express sert uniquement de passerelle OAuth et d’accès aux APIs Gmail / Microsoft Graph.

  • Tokens OAuth (access_token, refresh_token) en session HTTP.
  • Informations techniques nécessaires aux appels d’API (IDs de messages, filtres, paramètres de pagination).

Ces informations sont stockées en session (en mémoire ou Redis selon la configuration) et ne sont pas persistées dans une base de données applicative.

3. Cookies et sessions

L’application utilise un cookie de session HTTP pour maintenir votre authentification pendant la durée de la session.

  • Cookie signé via express-session.
  • Pas de cookies tiers de tracking ou de publicité.

4. Hébergement et journaux

En production, l’application est prévue pour être hébergée sur une plateforme type Railway/Render. Les journaux serveurs (logs) peuvent contenir des informations techniques (erreurs d’API, compteurs, métadonnées), mais jamais le contenu complet des emails.

5. Vos droits

Vous pouvez à tout moment :

  • Révoquer l’accès à votre compte depuis les consoles Google / Microsoft.
  • Supprimer les fichiers JSONL et métadonnées créés sur votre disque.
