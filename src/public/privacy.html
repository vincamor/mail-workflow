Privacy policy

1. Data processed

Mail Workflow is a local mailbox analysis tool. Emails are downloaded from your Gmail or Outlook account to your browser, then written to JSONL files in the folder you chose on your computer.

  • No email content is stored in a remote database.
  • Email and metadata files are created only in the local folder you select through the File System Access API.

2. Data that passes through the server

The Node.js/Express server acts only as a gateway for OAuth and for access to the Gmail / Microsoft Graph APIs.

  • OAuth tokens (access_token, refresh_token) in the HTTP session.
  • Technical information required for API calls (message IDs, filters, pagination parameters).

This information is stored in the session (in memory or in Redis depending on the configuration) and is not persisted to an application database.

3. Cookies and sessions

The application uses an HTTP session cookie to keep you authenticated for the duration of the session.

  • Cookie signed with express-session.
  • No third-party tracking or advertising cookies.

4. Hosting and logs

Mail Workflow is normally run locally, on your own machine. If you or your organisation choose to host it on a server, that instance is operated by whoever deployed it, and its privacy practices are theirs. Server logs may contain technical information (API errors, counters, metadata), but never the full content of emails.

5. Your rights

At any time you can:

  • Revoke access to your account from the Google / Microsoft consoles.
  • Delete the JSONL and metadata files created on your disk.
